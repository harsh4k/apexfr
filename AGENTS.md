# AGENTS.md — Late Apex site

Static, hand-written multi-page site (no framework, no build step for the
browser). Scroll-scrubbed video frames play behind each section.

## Commands

| Task | Command |
|---|---|
| Serve locally | `npm run serve` (port 5173, `PORT` env overrides) |
| Lint (syntax, links, ids, 300-line budget) | `npm run lint` |
| Full test suite (Playwright, 5 viewports) | `npm test` |
| Refresh visual baselines after an intended change | `npx playwright test tests/visual.spec.js --update-snapshots` |
| Rebuild pages from sources | `python .work/build_pages.py` |
| UI evidence for the loop | `node scripts/ui-evidence.mjs <task>` |
| Run all gates for a loop task | `sh scripts/gate.sh <task>` |

Playwright uses an existing Chrome build (see `playwright.config.js`); set
`PW_CHROME` to point elsewhere. Stop anything on port 5173 before
`runtime-verify.mjs`.

## Where things live

- `site/*.html` — **generated**. Edit `.work/pages/<name>.html` (page bodies)
  or `.work/legal/<name>.html` (legal fragments), then run the build script.
  The shared head, favicon, JSON-LD and script list live in
  `.work/build_pages.py`.
- `site/js/brand.js` — name, logo mark, email, profile links. Change once here.
- `site/js/pricing.js` — the rate card (`RATES`). Every price on the pricing
  page is painted from it.
- `site/js/director.js` — frame player: per-section shots, sub-frame blending,
  flare cuts. `site/js/shots.js` is generated by `.work/manifest.mjs`.
- `site/js/chrome.js` — nav, page transitions, loader, HUD, the render loop.
- `site/js/pieces.js` — scroll set pieces (orbit, lamps, pass-by bloom).
- `site/frames/<shot>/<width>/fNNN.webp` — generated, git-ignored.
  Regenerate: put `<shot>.mp4` in `.work/shots/`, run `.work/ingest2.sh <shot>`
  (2x motion interpolation + three WebP tiers), then `node .work/manifest.mjs`.

## Conventions

- Colours and type come from `site/css/tokens.css`; no raw hex in new rules.
- Files stay under 300 lines (lint enforces it).
- Animated elements use `data-split` / `data-reveal`; they only leave the
  "in" state when fully off-screen.
- A section behind which footage plays is `[data-chapter][data-shot]`;
  `.chapter--pin` sticks while its shot plays; `data-dim` darkens it;
  `data-busy` hides the HUD over dense content.
- Copy is plain and factual. No invented metrics, testimonials or clients.
